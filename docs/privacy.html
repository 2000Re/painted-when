Privacy Policy

Effective date: November 11, 2026 (first published November 5, 2026)

This Privacy Policy explains how Painted When? Uploader (“the app”) handles information. The app is a small open-source program (github.com/2000Re/painted-when) that generates a daily art-quiz video and uploads it to the YouTube channel @painted-when. It is operated by the owner of that channel for their own use only.

YouTube API Services

The app uses YouTube API Services. By using the app, you agree to be bound by the YouTube Terms of Service. Information accessed through YouTube API Services is also subject to the Google Privacy Policy.

Who uses the app

The app is used only by the channel owner to post to their own channel. It is not offered to the public, and no other person signs in to it.

Information the app accesses

When the channel owner authorizes the app with their Google account, it requests these permissions:

  • youtube.upload — to upload the daily video to the owner's channel.
  • youtube.readonly — to read the ID and name of the authorized channel, so that the app can stop if it is about to upload to the wrong channel.

The app does not access comments, subscribers, viewing history, analytics, or any other YouTube data, and it does not access any data of viewers or other YouTube users.

Information the app stores

  • Authorization credentials. The OAuth client ID, client secret, and refresh token are stored as encrypted GitHub Actions secrets in the channel owner's repository, and are used only to obtain access tokens for the uploads described above. Access tokens are kept in memory only while an upload runs.
  • Upload history. For each upload, the app records the episode number, the artwork it used, the video title, the video ID, the privacy status, and the upload time in a public file (upload_history.json) in the repository, so that it does not reuse an artwork. This contains no personal information.

The app does not collect personal information from viewers, and this website does not set its own cookies or run analytics.

This website

This website (2000re.github.io/painted-when) is hosted on GitHub Pages. The quiz pages embed the YouTube video for each quiz using YouTube's privacy-enhanced mode (youtube-nocookie.com) and show artwork images loaded directly from the museums' image servers (The Metropolitan Museum of Art and the Art Institute of Chicago). When you open a page, your browser connects to these services, which may receive your IP address and browser information as described in their own policies, and YouTube may store information on your device when you play a video. The quiz itself runs only in your browser; your answers are not sent anywhere.

How the information is used and shared

The information above is used only to upload videos to the owner's channel. It is not sold, shared with third parties, or used for advertising. The app sends data only to Google (YouTube Data API and Google Cloud Text-to-Speech, which receives only the quiz narration text) and to the museums' public APIs (which receive only requests for public artwork data).

Revoking access and deleting data

The channel owner can revoke the app's access to their Google account at any time from the Google security settings page (Third-party apps with account access). Deleting the GitHub Actions secrets removes the stored credentials. Uploaded videos can be deleted in YouTube Studio.

Changes to this policy

If this policy changes, the updated version will be posted on this page with a new effective date. The full history of changes is available in the repository.

Contact

Questions about this policy can be sent by opening an issue at github.com/2000Re/painted-when/issues.
